# ONE MORE DOOR — V2

A mobile-first arcade heist roguelite built around one temptation:

**You already have the objective. Do you escape — or open ONE MORE DOOR?**

## The actual point of a run

1. Infiltrate the building.
2. Find **3 access keycards** before Door 10.
3. Breach **The Vault** at Door 10.
4. Steal the **Core**.
5. Reach an extraction point.
6. Leave safely — or keep opening doors to overclock the Core and increase its value.
7. If you fail while carrying it, the Core is destroyed.

The old coin-only loop has been demoted to secondary upgrade currency. The Core is now the run objective.

## Meaningful door choices

Before the Vault, doors are routes through the building rather than generic reward categories. Keycard signals are shown when detected. A player can skip a keycard route for an easier option, but the game guarantees the contract can still be completed before Door 10.

After the Vault, the UI switches to **ESCAPE** mode. Every route shows how much it can increase Core value, while security heat rises the deeper you carry it.

## Long-term objective

Every successful extraction adds a recovered Core to the Case File. After **6 Core extractions**, the **Final Contract** unlocks:

**Steal another Core and carry it all the way to Door 20 to breach the Final Door.**

Completing that contract opens the game's ending while leaving endless high-score contracts available afterward.

## Existing gameplay retained

- Falling steel
- Laser grids
- Timing gates
- Closing walls
- Memory lanes
- Spinner rooms
- Minefields
- Gravity failures
- Glitch rooms
- Treasure routes
- Compound late-run rooms
- Boss/lockdown rooms every 10 doors
- Touch movement and tap-to-dash
- Permanent 3-slot loadout system
- Daily deterministic run
- Local records and statistics
- Procedural neon visuals, particles, screen shake, audio and haptics
- Offline/PWA support
- Capacitor Android build and rolling APK release workflow

## Progression

Successful extractions preserve gear coins used for permanent abilities. The Case File now tracks Cores extracted, best Core value, deepest successful escape, Vault breaches, keycards found and Final Door status.

All currency and rewards are fictional in-game progression only.
